# משחקי הגיבורים

אפליקציית משחקים בעברית לילדים בני 5, בנויה לטאבלט. בלי שרת, בלי התקנות ובלי תלויות: רק HTML, CSS ו-JavaScript.

## מה יש בפנים
- **אותיות**: מוצגת אות, והילד בוחר את התמונה שמתחילה בה. 20 שלבים להצלת דמות.
- **מספרים**: סופרים פירות, ירקות, חיות, כלי עבודה ודמויות ובוחרים את המספר. 20 שלבים להצלת דמות.
- **משחק זיכרון**: רמה אחת עם מקסימום הקלפים שנכנסים במסך. שחקן אחד או שני שחקנים.
- **פאזל**: פאזל אמיתי עם בליטות וחורים. גוררים כל חלק אל הלוח והוא נצמד כשמגיעים קרוב למקום הנכון. שתי רמות: בינוני (בערך חצי מהחלקים) וקשה (מקסימום החלקים שלא קטנים מדי).
- **מעקב אחרי אות ומספר**: עוברים עם האצבע על אות או ספרה, והמשחק מזהה כמה כוסה.
- **הרכבת מילה**: תמונה של מילה בת 2 או 3 אותיות, ובוחרים את האותיות לפי הסדר (כולל אותיות סופיות).
- **חריזה**: בוחרים את התמונה שמתחרזת עם המילה המוצגת.
- **חיבור וחיסור בתמונות**: סופרים ובוחרים את המספר המתאים.
- **המשך את התבנית**: תבניות של 2 ו-3 איברים (למשל אדום, כחול, אדום, כחול, ?).
- **יותר או פחות**: משווים שתי קבוצות ובוחרים איפה יש יותר או פחות.
- **צורות בתמונה**: מוצאים עיגול, משולש, ריבוע או מלבן בתוך ציור.
- **מה לא שייך**: ארבעה פריטים ואחד שונה.
- **הפכים**: מתאימים לכל מילה את ההפך שלה.
- **סיימון**: זוכרים רצף של צבעים וצלילים, עד 6 סבבים.
- **מבוך באצבע**: מובילים את הדמות אל הכוכב, 6 מבוכים שגדלים בהדרגה.
- **מיקס**: 20 שלבים שמערבבים את כל המשחקים.

תשובה נכונה מקדמת שלב, ותשובה שגויה מחזירה שלב אחורה. אחרי 20 שלבים מצילים דמות, ואז עוברים לדמות הבאה.
ההתקדמות נשמרת בדפדפן, בנפרד לכל מצב.

## הרצה
- פותחים את `index.html` בדפדפן, או
- מריצים שרת מקומי: `python3 -m http.server 8000` ופותחים `http://localhost:8000`

## העלאה ל-GitHub והפעלה בטאבלט
1. `git init && git add . && git commit -m "משחקי הגיבורים"`
2. יוצרים ריפו ב-GitHub ודוחפים אליו.
3. ב-GitHub: Settings, אחר כך Pages, ובוחרים Deploy from a branch והענף `main`.
4. פותחים את הכתובת בטאבלט. כדאי להוסיף למסך הבית (Share, Add to Home Screen) כדי לקבל מסך מלא.

## התאמה אישית
כל ההגדרות נמצאות ב-`js/config.js`.

**תמונות לזיכרון ולפאזל:** מעלים קבצים לתיקייה `images/` ורושמים אותם:
```js
images: ["images/ron.jpg", "images/gal.png", "images/family.jpg"]
```
בלי תמונות, המשחק משתמש באימוג׳י ובסצנות מובנות. אם יש פחות תמונות מזוגות בזיכרון, ההשלמה היא באימוג׳י.

**דמויות להצלה:** הדמויות המובנות הן ציורים מקוריים. כדי להשתמש בתמונות משלכם שמים אותן ב-`characters/` ומעדכנים:
```js
heroes: [
  { name: "השם", img: "characters/hero1.png" },
  ...
],
villain: { name: "השם", img: "characters/villain.png" }
```
מומלץ PNG עם רקע שקוף.

**שלבים וגדלים:** `storySteps` (כמה שלבים), `minMemoryCard`, `maxMemoryCards`, `minPuzzlePiece`, `maxPuzzlePieces`.

**אותיות, מילים, חריזות והפכים:** ב-`js/data.js` אפשר להוסיף ולערוך. ל-`build` מוסיפים מילים של 2 או 3 אותיות, ל-`rhymeSets` קבוצות של מילים שמתחרזות, ול-`opposites` זוגות הפכים.
